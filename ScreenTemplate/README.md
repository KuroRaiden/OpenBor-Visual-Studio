# main-openbor 1.1 screen assets

These menu backgrounds, bitmap fonts, animated GIFs, and menu music came from the supplied `main-openbor-1.1.zip` under `build/Data`. Studio uses them when you choose **Module → Screens → Use main-openbor 1.1 assets**.

The source archive credits the [OpenBOR Build Package (6391)](https://chronocrash.com/forum/resources/openbor.1/) as part of its base.
